## Hockey Fair Play Timer

React, Vite, Tailwind CSS, and Lucide React hockey shift/fair-play timer deployed with GitHub Pages.

### PWA
The app is configured as an installable Progressive Web App using vite-plugin-pwa. It uses the GitHub Pages base path `/hockey-fair-play-timer/` and can be installed to supported mobile home screens.

### Deployment
Pushes to `main` are built and deployed by the existing GitHub Pages workflow.
